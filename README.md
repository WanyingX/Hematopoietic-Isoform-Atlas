# Hematopoietic-Isoform-Atlas
Cell-type resolved transcript quantification across 
hematopoietic cell types derived from single-cell RNA-seq.

## Pipeline
1. scRNA-seq BAM deduplication
2. Split BAM by cell type
3. Merge donors per cell type  
4. StringTie transcript quantification

## Cell types
36 hematopoietic cell types
